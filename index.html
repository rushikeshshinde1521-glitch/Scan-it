What the server must do (for your IT team)

After each scan the app sends:

POST {server URL}/api/duplicates/check
Content-Type: application/json
X-API-Key: (your key, if set)

{ "traces": ["TABC123...", "TDEF456..."],
  "device": "dev-9f3k2l8x",
  "duns": "12V606038362" }

The server answers:

{ "duplicates": ["TABC123..."] }

An empty list means no duplicates. The included server.py already implements exactly this — IT only points it at the real trace database (2 marked spots) and gives it a URL the shopfloor phones can reach.
